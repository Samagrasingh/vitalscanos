# VitalScanOS — app site

This repository hosts the public information site for **VitalScanOS**, a camera-based
wellness check-in app for Android that processes everything on-device — no account,
nothing sent to servers. It contains the landing page plus the Privacy Policy and
Terms pages the app links to. The app source code is private and is not part of this
repository.

Published via GitHub Pages at https://samagrasingh.github.io/vitalscanos/
